# Overview

Looking for a guided walkthrough instead? Try the [ScaleFM Demo](https://colab.research.google.com/github/automl/scalefm/blob/master/tutorials/scalefm_demo.ipynb) in Google Colab.

1. **Convenience examples** show tensorboard compatibility and its integration, SLURM-scripting and understand file management within the evaluate pipeline function used in ScaleFM.

2. **Efficiency examples** show how to parallelize the evaluations, e.g. with PyTorch DDP and FSDP, natively or with PyTorch Lightning.

3. **Real-world examples** demonstrate how to apply ScaleFM to real-world problems, such as scaling studies.
