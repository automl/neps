# Citations

## Citation of The Software

For citing ScaleFM, please refer to the following:

### APA Style

```apa
 Alipour, N., Ambattu, P., Hog, J., Hutter, F. & Stoll, D. (2026). ScaleFM (Version 0.1.0) [Computer software]. https://github.com/automl/scalefm
```

### BibTex Style

```bibtex
@software{Alipour_Automated_Scaling_Analysis_2026,
author = {Nastaran Alipour, Philip Alex Ambattu, Johannes Hog, Frank Hutter and Danny Stoll},
month = nov,
title = {{ScaleFM}},
url = {https://github.com/automl/scalefm},
version = {0.1.0},
year = {2026}
}
```

## Citation of Papers

### Hierarchichal NAS with Context-free Grammars

If you have used the context-free grammar search space and the graph kernels implemented in ScaleFM (formerly NePS) for the paper [Hierarchical NAS](https://openreview.net/forum?id=Hpt1i5j6wh), please use the bibtex below:

```bibtex
@inproceedings{schrodi2023hierarchical,
title = {Construction of Hierarchical Neural Architecture Search Spaces based on Context-free Grammars},
author = {Simon Schrodi and Danny Stoll and Binxin Ru and Rhea Sanjay Sukthanker and Thomas Brox and Frank Hutter},
year = {2023},
booktitle = {Thirty-seventh Conference on Neural Information Processing Systems (NeurIPS 2023)},
keywords = {}
}
```
